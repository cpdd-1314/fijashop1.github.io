# ClickCollect Market

Pequeña aplicación de marketplace (compra/venta) construida con Node.js.

## Estructura

- `server.js` — servidor Node.js (API + archivos estáticos)
- `public/` — frontend (HTML, CSS, JS vanilla con vistas en `public/js/views/`)
- `data/db.json` — base de datos de ejemplo (json-server / archivo plano)
- `package.json` — dependencias y scripts

## Puesta en marcha

```bash
npm install
npm start
```

Luego abre `http://localhost:3000` (u el puerto que indique `server.js`).
